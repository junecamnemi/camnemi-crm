# Tuition unit rule pack (learned from Opus verdicts — Pro must follow)

Source: 13 Opus verdicts ({'semester': 7, 'unknown': 6}).

## Hard rules
1. summary/표 문구에 '연간'·'/년'·'1년' → 표 금액은 연간이므로 학기값 = round(krw/2)
2. summary/표 문구에 '학기'·'1학기 기준' → 표 금액 그대로 학기값
3. 계열표(…계열/…계) 행은 대학(…대학/…학부/…캠퍼스) 행이 있는 학교에서 grad_or_summary → 학부 범위에서 제외
4. 어학연수/어학당/한국어교육원 금액은 등록금이 아님 → 제외
5. '입학금 포함' 문구가 없으면 표 값은 수업료만; 포함 문구가 있으면 입학금 차감 후 비교
6. (미분류) 행은 신뢰하지 않음
7. 의·약·한의·치·수의 행은 학부지만 학교 대표 범위에서 분리해 별도 표기
