절차안내

회원가입

  • 회원가입 시 정확한 휴대폰 번호와 대학원 및 학과명 기입에 유의 바람.
  • 시험 종료 후 성적이 각 대학원으로 송부되며, 학과명이 불분명할 경우 송부에 어려움이 있을 수 있으며, 휴대폰 번호가 정확하지 않을 경우 안내 사항 전달이 누락될 수 있음.
  • 로그인 시 본교인증 오류가 뜨는 경우
    • 1) 이름이 올바르게 기입되지 않았거나 한글이름 기입란에 영문으로 기입 된 경우 본교인증 발생
    • 2) ATOM > 학생메뉴 > 개인정보수정으로 들어가 학생ID를 기입해 조회한 다음 이름 란을 한글이름으로 수정 후 저장
    • 3) 외국국적 : ATOM > 수강관리 > 수강신청 > 회원관리 > 학생ID 입력 후 조회 > 학번 입력 후 본교인증.
    • (외국국적의 학생 경우 이름(한글)에도 영문 이름을 기입해야 함. 예) GUO,YIJIA )

수강신청

  • 수강신청 방법 : 언어교육원 수강신청 홈페이지(http://atom.ewha.ac.kr) → 수강관리 → 수강신청-과정:대학원영어특강 → 체크박스 체크 후 확정 버튼
  • ★ 담당자 승인 후 홈페이지에서 수강료 결제 가능 (신청 당일 오후 3시 담당자 인괄 승인)


수강료납부

  • 담당자 승인 후 언어교육원 수강신청 홈페이지(http://atom.ewha.ac.kr) → 수강→ 수강관리 → 수강료 납부

    •   (결제 완료 후 , 결제완료 문자는 발송되지 않습니다.)

  • 수강료 270,000원 (25년도 봄학기부터 인상, 신규&재등록생 동일 금액)
  • 반드시 접수 마감시간까지 납입이 되어야 수강 가능합니다.

 강의 수강(사이버 캠퍼스)

- 수강신청 기간 이후 납입 완료한 학생에게 사이버캠퍼스 주소 문자 안내 

- 납입 완료된 학생에 한해 담당자가 일괄 등록, 개별 신청 불필요 (2025 여름학기부터 개정)

  • 1) 사이버캠퍼스 입장 후 (http://cyber.ewha.ac.kr)
  • 2) e-Class
  • 3) e-Class 목록 : [대학원영어특강] , 운영자: [언어교육원] (My e-class가 아닌 e-class 목록을 누른 후 검색)

  • 동영상 강의 수강은 출석퀴즈 제출기한 내에 완료하여야 출석 인정됩니다.

    •   (출석 퀴즈를 제출하였더라도 학습 진도율이 부족하면 출석으로 인정되지 않으니, 수강 후 반드시 진도율을 확인해주세요.)

  • 출석 인정을 받기 위해서는 기한 안에 수강을 완료(학습진도율 100% 기록)하고 출석퀴즈를 제출해야 합니다.

    Q) 출석 퀴즈란?

  • - 출석 퀴즈는 평가 시험 응시 자격을 위한 기준입니다. (총 14회 중 12회 이상 출석)
  • - 출석퀴즈는 복습 퀴즈 형태로 제공되며 평가시험 성적에는 반영되지 않습니다.
  • 강의자료집은 수업료에 포함.

    •   개강 약 일주일 전, 사이버캠퍼스 공지사항을 통해 강의자료집 수령 방법에 대한 안내하며,

      사이버캠퍼스에서 택배(착불) 또는 방문 수령 중에서 선택하실 수 있습니다.

평가시험 신청&강의평가

  • 언어교육원 홈페이지 → 로그인 → 수강 → 대학원영어시험 → 대학원영어시험 신청 → 해당학기 강좌 평가시험 신청 버튼 누른 후 결제 가능
  • 수업의 6/7 이상 출석(총 14회 수업 중 12회 이상) 응시 가능

    •   강의평가 완료 후 반드시 확정버튼을 눌러주세요.

  • 오프라인시험, 총 125문제 (100점 만점)
  • ID : 수강신청시 입력한 이메일 주소 / PW : 본인이 설정한 패스워드
  • 응시료 : 20,000원 (2025년도 봄학기부터 인상)
  • 강의평가 방법: http://atom.ewha.ac.kr 로그인 → 수강 → 수강관리 → 강의평가
  • 강의평가 완료 후 반드시 확정버튼을 눌러주세요.

    •   (확정이 되지 않으면 강의평가 미실시로 처리되어 성적조회가 되지 않습니다.)

  • 평가시험 신청기간과 강의평가 신청 기간이 동일합니다.

평가시험 결과

  • 언어교육원에서는 평가시험 시행, 채점, 점수 발표까지만 담당하고 있습니다.
  • 각 대학(원)에서 논문 제출 자격시험 합격/불합격 여부를 결정함.
  • 결과확인: http://atom.ewha.ac.kr 로그인 → 수강 → 대학원 영어시험→ 대학원 영어시험 평가결과

    •   (합격사정은 각 대학(원)에서 진행하며, 합격기준(커트라인), 합격여부 확인 기간도 대학(원)별로 상이함.)

      해당 점수로 논문 제출 자격시험 합격 여부 관련은 소속 대학원에 문의 바랍니다.

  • 동영상 강의 수강은 출석퀴즈 제출기한 내에 완료하여야 출석 인정됩니다.

    • (출석 퀴즈를 제출하였더라도 학습 진도율이 부족하면 출석으로 인정되지 않으니, 수강 후 반드시 진도율을 확인해주세요.)

  • 출석 인정을 받기 위해서는 기한 안에 수강을 완료(학습진도율 100% 기록)하고 출석퀴즈를 제출해야 합니다.

    Q) 출석 퀴즈란?

  • - 출석 퀴즈는 평가 시험 응시 자격을 위한 기준입니다. (총 14회 중 12회 이상 출석)
  • - 출석퀴즈는 복습 퀴즈 형태로 제공되며 평가시험 성적에는 반영되지 않습니다.
  • 교재: 교재비는 수업료에 포함.

    • 개강 전, 사이버캠퍼스 공지사항을 통해 교재 수령 방법에 대한 안내가 있을 예정입니다.

    교재 수령은 사이버캠퍼스에서 택배(착불) 또는 방문 수령 중에서 선택하실 수 있습니다.

평가시험 신청&강의평가

  • 언어교육원 홈페이지 → 로그인 → 수강 → 대학원영어시험 → 대학원영어시험 신청 → 해당학기 강좌 평가시험 신청 버튼 누른 후 결제 가능
  • 수업의 6/7 이상 출석(총 14회 수업 중 12회 이상) 응시 가능

    • 강의평가 완료 후 반드시 확정버튼을 눌러주세요.

  • 오프라인시험, 총 125문제 (100점 만점)
  • ID : 수강신청시 입력한 이메일 주소 / PW : 본인이 설정한 패스워드
  • 응시료 : 20,000원 (2025년도 봄학기부터 인상)
  • 강의평가 방법: http://atom.ewha.ac.kr 로그인 → 수강 → 수강관리 → 강의평가
  • 강의평가 완료 후 반드시 확정버튼을 눌러주세요.

    • (확정이 되지 않으면 강의평가 미실시로 처리되어 성적조회가 되지 않습니다.)

  • 평가시험 신청기간과 강의평가 신청 기간이 동일합니다.

평가시험 결과

  • 결과확인: http://atom.ewha.ac.kr 로그인 → 수강 → 수강관리 → 수강성적조회
  • 각 대학(원)에서 논문 제출 자격시험 합격/불합격 여부를 결정함.

    • (합격사정은 각 대학(원)에서 진행하며, 합격기준(커트라인), 합격여부 확인 기간도 대학(원)별로 상이함.)

  • 언어교육원에서는 평가시험 시행, 채점, 점수 발표까지만 담당하고 있습니다. 

    • 해당 점수로 논문 제출 자격시험 합격 여부 관련은 소속 대학원에 문의 바랍니다.
